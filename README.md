\# Project Dataset



\### Dataset Theme



Social Media User Behavior Analysis



\### Features



\- User ID

\- Age

\- Daily Screen Time

\- Social Media Hours

\- Sleep Hours

\- Exercise Minutes

\- Study/Work Hours

\- Productivity Score

\- Stress Level

\- Platform



\---



\# Key Findings



\### Insight 1



Users with higher screen time generally exhibit lower productivity scores.



\### Insight 2



Users who sleep longer tend to experience lower stress levels.



\### Insight 3



Regular exercise is positively associated with productivity.



\### Insight 4



Balanced digital habits contribute to improved well-being and performance.



\---



\#  Statistical Validation



\### Hypothesis



\*\*Null Hypothesis (H₀):\*\*

Screen time does not affect productivity.



\*\*Alternative Hypothesis (H₁):\*\*

Screen time affects productivity.



\### Method Used



\- Independent T-Test



\### Outcome



The statistical analysis validated the relationship between screen time and productivity based on the calculated p-value.
